# Assets

Exporturi de diagrame, capturi de dashboard anonimizate, rezultate de benchmark.

Convenție de denumire: `NN-nume-caz__descriere.ext` (ex. `03-large-scale-data-platform__ingestion-topology.svg`).

Înainte de a adăuga orice fișier aici, treci prin secțiunea de anonimizare din
`../EVIDENCE-CHECKLIST.md`. Nu adăuga capturi cu date reale de clienți, hostname-uri
interne sau credențiale — nici expirate.
